# Vynaris

OpenAI-compatible LLM inference gateway with evidence-based model routing and a per-request cost receipt attached to every response. Offers routed inference at provider list price plus a small markup, Vynaris-hosted reduced-refusal models, and enterprise self-hosted deployments. Early beta.

## APIs

- **Vynaris Gateway API** — REST API in OpenAI Chat Completions wire format. Primary endpoint POST /v1/chat/completions with SSE streaming and tool/function-calling passthrough. Supporting endpoints for ping, usage, ledger, and programmatic self-onboarding. Bearer API key auth. Includes llms.txt and an agents.md agent-facing runbook. (`https://api.vynaris.com/v1`)
